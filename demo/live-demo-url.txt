NOT DEPLOYED — run locally using docs/setup-guide.md

To run the application locally:
  1. Clone: git clone https://github.com/niyati-trivedi/bob-ai-hackathon-Tech-Titans.git
  2. Install: cd bob-ai-hackathon-Tech-Titans && bun install
  3. Run: bun run dev
  4. Open: http://localhost:5173

The application will be running at http://localhost:5173 with full demo data and UI components.
See docs/setup-guide.md for complete instructions.
